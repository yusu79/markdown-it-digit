# 数値変換仕様

## 概要

`markdown-it-digit` は、Markdown内の専用記法で指定した整数をlocaleごとの形式へ変換する `markdown-it` プラグインである。専用記法を使用していない通常の数値は変更しない。

## Public API

本パッケージはCommonJSのmarkdown-itプラグイン関数だけをPublic APIとして公開する。

```js
const MarkdownIt = require("markdown-it");
const markdownItDigit = require("markdown-it-digit");

const md = new MarkdownIt().use(markdownItDigit);
```

plugin options、ESM用エントリポイント、外部locale登録APIは提供しない。

以下はInternal APIであり、互換性を保証せず、package subpathからも公開しない。

- `src/parser.js`
- `src/renderer.js`
- `src/locales/*`
- `createEastAsianFormatter`
- formatterレジストリ
- digit tokenの内部表現と `token.meta.digit`

## 基本構文

```text
$<number>${<locale>}
```

| 要素 | 仕様 |
| --- | --- |
| `$` | 開始記号 |
| `<number>` | 1文字以上のASCII数字（`0`～`9`） |
| `${...}` | locale指定 |
| `<locale>` | ASCII英字で始まり、ASCII英数字とハイフン区切りの追加部分を使用できる識別子 |

整数は文字列として扱い、JavaScriptの `Number` へ変換しない。これにより、先頭ゼロと最大安全整数を超える桁を保持する。負数と小数はv1.0.0の変換対象ではない。locale識別子は大文字と小文字を区別する。

## 対応locale

| locale | 表記方式 |
| --- | --- |
| `en` | 右から3桁ごとにカンマで区切る |
| `in` | 右端を3桁、その左側を右から2桁ごとにカンマで区切る |
| `jp` | 日本語の万進法単位を4桁ごとに挿入する |
| `cn` | 簡体字中国語の万進法単位を4桁ごとに挿入する |
| `kr` | 韓国語の万進法単位を4桁ごとに挿入する |
| `tw` | 繁体字中国語の万進法単位を4桁ごとに挿入する |

`jp`、`cn`、`kr`、`tw` は本プロジェクト独自のフォーマット識別子であり、ISO言語コードやBCP 47言語タグとして扱わない。

## 桁区切り形式

`en` は右から3桁、`in` は右端を3桁、その左側を2桁ごとに区切り、HTML要素を含まないプレーンテキストを出力する。

| 入力 | 出力 |
| --- | --- |
| `$1234567${en}` | `1,234,567` |
| `$123456789${in}` | `12,34,56,789` |
| `$0001000${en}` | `0,001,000` |

## 東アジアの万進法形式

`jp`、`cn`、`kr`、`tw` は右端から4桁ごとに数値を分割し、境界へlocale固有の単位を `<sub>` 要素として挿入する。

| 指数 | `jp` | `cn` | `kr` | `tw` |
| ---: | --- | --- | --- | --- |
| 10⁴ | 万 | 万 | 만 | 萬 |
| 10⁸ | 億 | 亿 | 억 | 億 |
| 10¹² | 兆 | 兆 | 조 | 兆 |
| 10¹⁶ | 京 | 京 | 경 | 京 |
| 10²⁰ | 垓 | 垓 | 해 | 垓 |
| 10²⁴ | 𥝱 | 秭 | 자 | 秭 |
| 10²⁸ | 穣 | 穰 | 양 | 穰 |
| 10³² | 溝 | 沟 | 구 | 溝 |
| 10³⁶ | 澗 | 涧 | 간 | 澗 |
| 10⁴⁰ | 正 | 正 | 정 | 正 |
| 10⁴⁴ | 載 | 载 | 재 | 載 |
| 10⁴⁸ | 極 | 极 | 극 | 極 |
| 10⁵² | 恒河沙 | 恒河沙 | 항하사 | 恆河沙 |
| 10⁵⁶ | 阿僧祇 | 阿僧祇 | 아승기 | 阿僧祇 |
| 10⁶⁰ | 那由他 | 那由他 | 나유타 | 那由他 |
| 10⁶⁴ | 不可思議 | 不可思议 | 불가사의 | 不可思議 |
| 10⁶⁸ | 無量大数 | 无量大数 | 무량대수 | 無量大數 |

| 入力 | HTML出力 |
| --- | --- |
| `$123456789${jp}` | `1<sub>億</sub>2345<sub>万</sub>6789` |
| `$123456789${cn}` | `1<sub>亿</sub>2345<sub>万</sub>6789` |
| `$123456789${kr}` | `1<sub>억</sub>2345<sub>만</sub>6789` |
| `$123456789${tw}` | `1<sub>億</sub>2345<sub>萬</sub>6789` |

元の数字とゼロだけの4桁グループは省略しない。例えば `$100000000${jp}` は `1<sub>億</sub>0000<sub>万</sub>0000` となる。

名前を付与する最大単位は10⁶⁸に対応する単位までとする。それを超える上位桁にも新しい単位名は付与せず、数値として保持する。

## 変換対象

正しい専用記法を含む通常のインラインテキストを変換する。強調などのMarkdown装飾内、Markdownリンクの表示テキスト、HTMLタグ間の通常テキストも対象とする。1行に複数の専用記法を記述でき、記法同士を空白なしで隣接させることもできる。

## 変換対象外

次の領域にある専用記法は変換しない。

- fenced code block
- インデントされたcode block
- インラインコード
- URLまたは明示的なURI scheme内
- `www.` で始まるURL内
- Markdownリンクのリンク先
- Markdownの自動リンク内
- HTML属性内
- HTMLを有効にした場合のHTMLコメント内
- バックスラッシュでエスケープされた記法

URI schemeを持たない単なるパス風テキストは通常のインラインテキストとして扱う。例えば `docs/$1000${en}` の専用記法は変換する。プラグイン自体はmarkdown-itのHTMLオプションを有効化しない。

## エスケープ

専用記法を文字列として表示する場合はMarkdownのバックスラッシュエスケープを使用する。

```text
\$1000000${en}
```

この入力は数値変換されず、表示上は `$1000000${en}` となる。専用記法の直前に偶数個のバックスラッシュがある場合は、Markdownのエスケープ規則に従い変換対象となる。

## 未対応locale

構文として有効でもformatterが登録されていないlocaleは、元の専用記法をそのまま出力する。`unknown`、`EN`、`en-US` はいずれも未対応localeであり、レンダリング処理全体をエラーにしない。

## 不正入力とエラー

構文として成立しない入力は変換しない。空の数値やlocale、数字以外の数値、負数、小数、不完全な区切り記号などが該当する。

formatter内部で予期しない例外が発生した場合もMarkdown全体のレンダリングを失敗させず、対象の元記法をHTMLエスケープして出力する。

## HTML出力と安全性

`en` と `in` はプレーンテキストを返す。東アジア形式の `<sub>` 要素と単位文字列はプラグイン内の固定データから生成し、入力値をHTMLとして挿入しない。

未対応locale、不正な内部解析情報、formatter例外から元記法へフォールバックする場合はHTMLエスケープして出力する。

## markdown-itとの統合

Markdown全体への単純な文字列置換は行わず、markdown-itのinline ruleとrenderer ruleを使用する。これにより、変換対象のテキストとコード、URL、HTML領域を区別する。
