# 数値変換仕様

このプラグインは、Markdown 内に専用記法で記述された数値を、指定されたロケールの表記方法へ変換する `markdown-it` プラグインである。

通常の数値は変更せず、以下の専用記法で指定された数値のみを変換対象とする。

```text
$<number>${<locale>}
```

例:

```text
$1000000${en}
$1000000${jp}
```

---

## 基本構文

```text
$<number>${<locale>}
```

各要素の意味は以下のとおり。

| 要素         | 内容            |
| ---------- | ------------- |
| `$`        | 数値変換の開始記号     |
| `<number>` | 変換対象となる数値     |
| `${...}`   | 変換方式の指定       |
| `<locale>` | 数値表記に使用するロケール |

例:

```text
$1000000${en}
```

`en` の数値表記ルールを使用して `1000000` を変換する。

---

## 英語表記

ロケール:

```text
en
```

3桁ごとにカンマで区切る。

### 変換例

|              入力 |          出力 |
| --------------: | ----------: |
|    `$1000${en}` |     `1,000` |
|   `$10000${en}` |    `10,000` |
|  `$100000${en}` |   `100,000` |
| `$1000000${en}` | `1,000,000` |
| `$1234567${en}` | `1,234,567` |

生成される HTML:

```html
1,000,000
```

---

## 日本語表記

ロケール:

```text
jp
```

日本語の4桁単位を使用して数値を区切る。

数値自体は省略せず、**「万」「億」「兆」「京」などの桁単位を `<sub>` 要素として下付き表示する。**

### 基本単位

`jp` では、万から無量大数まで以下の単位を使用する。

|   指数 | 単位   | HTML              |
| ---: | ---- | ----------------- |
|  10⁴ | 万    | `<sub>万</sub>`    |
|  10⁸ | 億    | `<sub>億</sub>`    |
| 10¹² | 兆    | `<sub>兆</sub>`    |
| 10¹⁶ | 京    | `<sub>京</sub>`    |
| 10²⁰ | 垓    | `<sub>垓</sub>`    |
| 10²⁴ | 𥝱   | `<sub>𥝱</sub>`   |
| 10²⁸ | 穣    | `<sub>穣</sub>`    |
| 10³² | 溝    | `<sub>溝</sub>`    |
| 10³⁶ | 澗    | `<sub>澗</sub>`    |
| 10⁴⁰ | 正    | `<sub>正</sub>`    |
| 10⁴⁴ | 載    | `<sub>載</sub>`    |
| 10⁴⁸ | 極    | `<sub>極</sub>`    |
| 10⁵² | 恒河沙  | `<sub>恒河沙</sub>`  |
| 10⁵⁶ | 阿僧祇  | `<sub>阿僧祇</sub>`  |
| 10⁶⁰ | 那由他  | `<sub>那由他</sub>`  |
| 10⁶⁴ | 不可思議 | `<sub>不可思議</sub>` |
| 10⁶⁸ | 無量大数 | `<sub>無量大数</sub>` |

### 変換例

|                入力 | 出力                                  |
| ----------------: | ----------------------------------- |
|     `$10000${jp}` | `1<sub>万</sub>0000`                 |
|    `$100000${jp}` | `10<sub>万</sub>0000`                |
|   `$1000000${jp}` | `100<sub>万</sub>0000`               |
|  `$10000000${jp}` | `1000<sub>万</sub>0000`              |
| `$100000000${jp}` | `1<sub>億</sub>0000<sub>万</sub>0000` |
| `$123456789${jp}` | `1<sub>億</sub>2345<sub>万</sub>6789` |

単位は HTML 上では `<sub>` として出力する。

例えば、

```text
$1000000${jp}
```

は以下の HTML へ変換する。

```html
100<sub>万</sub>0000
```

また、

```text
$123456789${jp}
```

は以下へ変換する。

```html
1<sub>億</sub>2345<sub>万</sub>6789
```

### 単位の省略

日本語表記では、単位を挿入しても元の数字を削除しない。

例えば `100000000` は、

```text
1億
```

とは変換せず、

```html
1<sub>億</sub>0000<sub>万</sub>0000
```

と変換する。

これにより、元の数値の各桁を保持したまま、日本語における桁の境界を視覚的に確認できる。

### 4桁単位での分割

日本語表記では、右端から4桁ごとに数値を分割する。

例えば、

```text
1234567890123
```

は内部的に次のように分割される。

```text
1 | 2345 | 6789 | 0123
```

各境界には対応する日本語単位を付与する。

```html
1<sub>兆</sub>2345<sub>億</sub>6789<sub>万</sub>0123
```

したがって、日本語表記は数値を短縮する機能ではなく、日本語の数値単位を桁位置のガイドとして付加する機能とする。

## ロケールごとの変換ルール

各ロケールは独立した変換ルールを持つ。

ルールには主に以下を定義する。

* 桁区切り
* 区切り文字
* グループ化する桁数
* 数値単位
* 単位を挿入する位置
* 単位の HTML 表現
* 小数点記号
* 負数の表記方法

例えば、3桁区切りを使用するロケールでも、区切り文字が異なる場合がある。

概念上は以下のような設定を持つ。

```js
{
    locale: "en",
    grouping: [3],
    groupSeparator: ",",
    decimalSeparator: "."
}
```

別のロケールでは以下のような設定を持つことができる。

```js
{
    locale: "de",
    grouping: [3],
    groupSeparator: ".",
    decimalSeparator: ","
}
```

日本語のように単位そのものを挿入するロケールについては、単位テーブルを定義する。

```js
{
    locale: "jp",
    units: [
        { exponent: 4, label: "万" },
        { exponent: 8, label: "億" },
        { exponent: 12, label: "兆" },
        { exponent: 16, label: "京" },
        { exponent: 20, label: "垓" },
        { exponent: 24, label: "𥝱" },
        { exponent: 28, label: "穣" },
        { exponent: 32, label: "溝" },
        { exponent: 36, label: "澗" },
        { exponent: 40, label: "正" },
        { exponent: 44, label: "載" },
        { exponent: 48, label: "極" },
        { exponent: 52, label: "恒河沙" },
        { exponent: 56, label: "阿僧祇" },
        { exponent: 60, label: "那由他" },
        { exponent: 64, label: "不可思議" },
        { exponent: 68, label: "無量大数" }
    ]
}
```

この構造により、ロケールを追加しても数値解析部分を変更せずに対応できる設計とする。

## 初期対応ロケール

最初の実装では以下を必須対応とする。

| ロケール | 表記方式              |
| ---- | ----------------- |
| `en` | 3桁区切り             |
| `jp` | 万から無量大数までの日本語4桁単位 |

その他のロケールは、ロケール定義を追加することで順次対応する。

将来的には、少なくとも以下の数値表記体系への対応を想定する。

* 英語圏
* 日本
* 中国
* 韓国
* インド
* ドイツ語圏
* フランス語圏
* スペイン語圏
* イタリア語圏
* その他の地域固有の数値表記

単純に国ごとのファイルを大量に作成するのではなく、同一の数値表記体系を使用する地域では共通ルールを再利用できる設計とする。

## 日本語単位

`jp` では、日本語の大数単位を使用して数値の桁を表示する。

### 日本語単位

`jp` では、以下の単位を使用する。

|   指数 | 単位   | 読み       |
| ---: | ---- | -------- |
|  10⁴ | 万    | まん       |
|  10⁸ | 億    | おく       |
| 10¹² | 兆    | ちょう      |
| 10¹⁶ | 京    | けい       |
| 10²⁰ | 垓    | がい       |
| 10²⁴ | 𥝱   | じょ       |
| 10²⁸ | 穣    | じょう      |
| 10³² | 溝    | こう       |
| 10³⁶ | 澗    | かん       |
| 10⁴⁰ | 正    | せい       |
| 10⁴⁴ | 載    | さい       |
| 10⁴⁸ | 極    | ごく       |
| 10⁵² | 恒河沙  | ごうがしゃ    |
| 10⁵⁶ | 阿僧祇  | あそうぎ     |
| 10⁶⁰ | 那由他  | なゆた      |
| 10⁶⁴ | 不可思議 | ふかしぎ     |
| 10⁶⁸ | 無量大数 | むりょうたいすう |

### 採用する命数法

日本語の大数には、歴史的に複数の命数法が存在する。

本プラグインでは、**万以降を4桁ごとに区切る万進法**を採用する。

そのため、以下のように定義する。

```text
万         = 10^4
億         = 10^8
兆         = 10^12
京         = 10^16
垓         = 10^20
𥝱         = 10^24
穣         = 10^28
溝         = 10^32
澗         = 10^36
正         = 10^40
載         = 10^44
極         = 10^48
恒河沙     = 10^52
阿僧祇     = 10^56
那由他     = 10^60
不可思議   = 10^64
無量大数   = 10^68
```

資料によっては、恒河沙以降を8桁ごとに進め、

```text
恒河沙     = 10^56
阿僧祇     = 10^64
那由他     = 10^72
不可思議   = 10^80
無量大数   = 10^88
```

とする命数法も存在する。

本プラグインでは、この体系は採用しない。

### 表記の異なる単位

日本語の大数には、資料によって異なる漢字が使用される単位がある。

本プラグインでは出力を統一するため、使用する表記を固定する。

| 採用する表記 | 異表記の例 |
| ------ | ----- |
| 𥝱     | 秭、杼   |
| 阿僧祇    | 阿僧祗   |
| 那由他    | 那由多   |

異表記は出力には使用しない。

### 出力例

```text
$10000${jp}
```

```html
1<sub>万</sub>0000
```

```text
$100000000${jp}
```

```html
1<sub>億</sub>0000<sub>万</sub>0000
```

```text
$1234567890123${jp}
```

```html
1<sub>兆</sub>2345<sub>億</sub>6789<sub>万</sub>0123
```

無量大数まで同じ規則を適用する。

### 対応範囲

日本語として名前を付与する単位は、`無量大数`（10⁶⁸）までとする。

10⁶⁸を超える数値についても変換自体は行い、`無量大数`を最大の名前付き単位として使用する。

無量大数より上位の部分には、新しい単位名を付与しない。

例えば、10⁷²は、

```text
10000 × 10^68
```

であるため、以下のように扱う。

```html
10000<sub>無量大数</sub>0000<sub>不可思議</sub>0000<sub>那由他</sub>0000<sub>阿僧祇</sub>0000<sub>恒河沙</sub>0000<sub>極</sub>0000<sub>載</sub>0000<sub>正</sub>0000<sub>澗</sub>0000<sub>溝</sub>0000<sub>穣</sub>0000<sub>𥝱</sub>0000<sub>垓</sub>0000<sub>京</sub>0000<sub>兆</sub>0000<sub>億</sub>0000<sub>万</sub>0000
```

この場合、`10000` の部分に対応する新しい日本語単位は定義しない。

同様に、さらに大きな数値についても、無量大数より上位の桁は数値としてそのまま保持する。

これにより、

* 歴史的に定義の定まらない単位を独自に追加しない
* 元の数値を失わない
* 無量大数を超える数値でも変換処理を継続できる
* JavaScript の `Number` の最大安全整数に依存しない

という方針を維持する。

## ロケール

数値の変換方式はロケールごとに定義する。

ロケール名には、原則として短い識別子を使用する。

例:

```text
en
jp
de
fr
es
it
ko
zh
```

将来的には必要に応じて地域を含むロケールも使用できる。

```text
en-US
en-GB
fr-FR
de-DE
zh-CN
zh-TW
```

同じ言語でも地域によって数値表記が異なる場合は、地域付きロケールを優先する。

例:

```text
$1000000${en-US}
$1000000${de-DE}
```

## 数値

初期仕様では整数を変換対象とする。

```text
$1000${en}
$1000000${jp}
```

以下については将来的な拡張対象とする。

### 負数

```text
$-1000000${en}
```

想定結果:

```text
-1,000,000
```

### 小数

```text
$1234567.89${en}
```

想定結果:

```text
1,234,567.89
```

### 非常に大きな整数

JavaScript の `Number` で安全に扱えない整数についても考慮する。

数値変換処理では、可能な限り元の数値を文字列として解析し、不要な浮動小数点変換を行わない。

これにより、以下のような値でも桁落ちを防ぐ。

```text
$12345678901234567890${en}
```

---

## 変換対象

専用記法として正しく記述されたものだけを変換する。

```text
$1000000${en}
```

通常の数値は変換しない。

```text
1000000
```

したがって、

```markdown
価格は1000000円です。

変換すると $1000000${en} です。
```

は次のようにレンダリングされる。

```text
価格は1000000円です。

変換すると 1,000,000 です。
```

---

## 変換対象外

以下の場所に記述された専用記法は変換しない。

* コードブロック内
* インラインコード内
* URL 内

### コードブロック

````markdown
```text
$1000000${en}
```
````

変換しない。

### インラインコード

```markdown
`$1000000${en}`
```

変換しない。

### URL

```text
https://example.com/$1000000${en}
```

変換しない。

Markdown のリンク先 URL についても変換しない。

```markdown
[example](https://example.com/$1000000${en})
```

---

## HTML 出力

通常の3桁区切りなど、HTML要素を必要としない変換ではプレーンテキストを出力する。

入力:

```text
$1000000${en}
```

HTML:

```html
1,000,000
```

単位を装飾する必要があるロケールでは HTML を生成できる。

入力:

```text
$123456789${jp}
```

HTML:

```html
1<sub>億</sub>2345<sub>万</sub>6789
```

生成する HTML はプラグイン側で管理し、入力値をそのまま HTML として挿入しない。

---

## 未対応ロケール

指定されたロケールが存在しない場合は、元の記述をそのまま残す。

入力:

```text
$1000000${unknown}
```

出力:

```text
$1000000${unknown}
```

レンダリング処理全体をエラーにしない。

---

## 不正な構文

構文として成立していないものは変換しない。

例えば以下は変換対象外とする。

```text
$${en}
$abc${en}
$1000000$
$1000000{}
$1000000${}
```

これらは入力された文字列をそのまま出力する。

---

## エスケープ

専用記法を文字列として表示したい場合は、Markdown のバックスラッシュエスケープを使用できるようにする。

入力:

```text
\$1000000${en}
```

表示:

```text
$1000000${en}
```

この場合、数値変換は行わない。

---

## 複数記述

1行に複数の数値変換を記述できる。

入力:

```text
$1000${en} / $10000${en} / $1000000${en}
```

出力:

```text
1,000 / 10,000 / 1,000,000
```

異なるロケールを同時に使用することもできる。

入力:

```text
英語: $1000000${en}
日本語: $1000000${jp}
```

出力:

英語: 1,000,000
日本語: 100<sub>万</sub>0000

---

## Markdown-it との統合

プラグインは Markdown 全体を単純な正規表現で置換しない。

Markdown-it のトークンを利用し、変換可能なテキストノードのみを処理する。

これにより以下を保護する。

* fenced code
* code block
* inline code
* link destination
* HTML 属性
* その他 Markdown-it がコードまたは URL として解析した領域

基本的には通常のインラインテキストに含まれる専用記法のみを変換する。

## ロケール追加

新しいロケールは、数値解析処理そのものを変更せず追加できる設計とする。

概念的には以下のような構成とする。

```text
src/
├── index.js
├── parser.js
├── renderer.js
└── locales/
    ├── en.js
    ├── jp.js
    ├── de.js
    ├── fr.js
    ├── es.js
    ├── it.js
    ├── ko.js
    └── zh.js
```

各ロケールモジュールが、その地域における数値表記ルールを担当する。

これにより世界各国の数値表記を段階的に追加できる。

---

## 設計方針

このプラグインは以下を基本方針とする。

1. 通常の数値には影響を与えない
2. 明示的にロケールを指定した数値だけを変換する
3. Markdown のコードや URL を破壊しない
4. 数値を可能な限り文字列として処理し、精度を失わない
5. ロケールごとの処理を独立させる
6. 新しい国・地域の数値表記を容易に追加できる
7. 未対応ロケールや不正な構文によって Markdown のレンダリングを失敗させない
8. 入力された HTML を無条件に出力しない
9. 同一文書内で複数のロケールを使用できる
